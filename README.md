# Student Registration - Flask CRUD Application

A simple Flask web application demonstrating full CRUD (Create, Read, Update, Delete)
operations for managing student registration records, using Flask-SQLAlchemy and SQLite.

## Features
- Register a new student (Create)
- View all registered students (Read)
- Edit existing student details (Update)
- Delete a student record (Delete)
- Flash messages for success/error feedback
- Secure, dynamically generated secret key for session/flash message signing
- SQLite database auto-created on first run
